# ElectroElite — Multi-Brand Electronics E-Commerce Website

A high-performance, modern multi-brand electronics e-commerce web application selling smartphones, televisions, refrigerators, washing machines, air conditioners, laptops, and accessories.

## 🎨 Theme & Design System
- **Midnight Navy** (`#0A192F` / `#0D1B2A`): Deep premium contrast for navbars, hero sections, and headers
- **Warm White** (`#FBFBF9` / `#F8F9FA`): Clean, warm canvas for product presentation
- **Electric Orange** (`#FF6B35` / `#F97316`): High-energy accents, CTAs, sale badges, and highlight banners
- **Teal** (`#0D9488` / `#14B8A6`): Spec badges, verified stock, ratings, and technical highlights

---

## 🚀 Tech Stack
- **Frontend:** React 19, Vite, React Router DOM 7, Lucide Icons, Custom Responsive CSS
- **Backend:** Node.js, Express 5, MongoDB (with resilient auto-fallback), JWT Authentication, Bcrypt
- **Authentication:** Email & Password only (Zero 3rd-party/Google OAuth)

---

## 📦 Features

- **Catalog & Categories:** Smartphones, Televisions, Refrigerators, Washing Machines, Air Conditioners, Laptops, Accessories
- **Brands:** Apple, Samsung, Sony, LG, ASUS, Dell, HP, Whirlpool, Daikin, OnePlus, boAt
- **Search & Filters:** Real-time search, brand filter, category filter, price range slider, in-stock toggle, sorting
- **Product Details:** High-res image gallery, technical specification sheets, customer ratings & reviews, stock indicators
- **Cart & Wishlist:** Real-time quantity adjustments, price calculations, local & synced persistence
- **Demo Checkout & Orders:** Multi-step checkout, mock payment options (COD, UPI, Card), order summary & order history
- **Admin Dashboard:** Inventory controls, product creation/editing, stock restock/sell, order status tracking
- **Seed Data:** Over 25 realistic electronics products with realistic specs, warranty, and pricing without duplicates

## 🛠️ Quick Start Guide

### Prerequisites
- Node.js (v18+ recommended, detected v24)
- npm

### 1. Backend Setup
```bash
cd server
npm.cmd install
npm.cmd start
```
*Backend runs on `http://localhost:5003`*

### 2. Frontend Setup
```bash
cd client
npm.cmd install
npm.cmd run dev
```
*Frontend runs on `http://localhost:5173`*

### 3. Demo Credentials
- **Admin Email:** `admin@electroelite.com`
- **Admin Password:** `admin123`
- Or register a new customer account directly from the register page.
